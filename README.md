# MohuanLED RGB Studio (Windows prototype)

A community-protocol-based desktop prototype for BJ_LED_M / MohuanLED BLE strips.

## Features in this prototype
- Dark RGB Gaming UI
- BLE scan/connect/disconnect
- Manual RGB color picker and brightness
- Software-generated Rainbow, Breathing, Color Wave, Strobe and Fade
- Screen Sync using average desktop color
- Experimental Music Sync using Windows loopback audio when available

## Important limitations
- This is a source prototype, not a signed installer or verified executable.
- I cannot test your exact strip/firmware here. BLE UUID and packet layouts vary by controller.
- Default write characteristic is `0000ee01-0000-1000-8000-00805f9b34fb` and packet is `69 96 05 02 RR GG BB 00`, based on community documentation. If your device does not respond, try checking the discovered writable characteristics and the alternate protocol option. Do not assume every BJ_LED_M firmware uses the same characteristic/packet.
- The UI lists candidate devices by name; if scanning fails, check Windows Bluetooth is enabled, keep the strip nearby, and close MohuanLED on the phone.
- Effects are generated by sending changing colors over BLE. They may appear less smooth than built-in controller effects and affect the entire strip as one color.
- Screen Sync sends a sampled average color. Multi-zone Ambilight needs a controller protocol supporting zones.
- Music Sync is experimental; Windows audio loopback support varies by driver and permissions.
- This prototype does not modify device firmware or access phone data.

## Setup
1. Install Python 3.10+ for Windows from the official Python website and enable "Add Python to PATH".
2. Unzip this folder.
3. Double-click `install.bat`.
4. Double-click `start.bat`.
5. Turn on the LED strip, close the MohuanLED phone app, press Scan, select `BJ_LED_M`, then Connect.
6. Try a static color before running effects.

## Build a standalone EXE (optional)
After installing dependencies, run:
` .venv\Scripts\python -m pip install pyinstaller`
then:
` .venv\Scripts\pyinstaller --noconfirm --windowed --name MohuanLED_RGB_Studio app.py`

Bluetooth behavior may differ when packaged. Test the Python version first.
